# تەختەکلیلی کوردی نوێ — Android starter source

## ئامانج
- Android 8.0+ (minSdk 26)
- سەرەتای Android Input Method Editor
- subtype بۆ کوردی سۆرانی، ئینگلیزی و عەرەبی
- ڕووکاری سەرەتایی و پەڕەی چالاککردن/هەڵبژاردنی تەختەکلیل

## Build
پڕۆژەکە لە Android Studio بکەرەوە، Gradle Sync بکە، پاشان:
`Build > Build Bundle(s) / APK(s) > Build APK(s)`

## دۆخی ئەم وەشانە
ئەمە scaffold ـی سەرەتاییە، نەک وەشانی تەواو و ئامادەی بڵاوکردنەوە. ڕیزبەندی پیتەکانی کوردی لێرە placeholder ـە و دەبێت بە وێنەی ڕەچاوکراوی بەکارهێنەر بگونجێندرێت. هێشتا کلیپبۆردی مێژوویی، بەڕێوەبردنی دەستەواژە، ڕێکخستنی پیت و ڕیزەکان، گۆڕینی فۆنت و ڕەنگ، وەرگێڕانی ئۆفلاین، GIF/ستیکەر، swipe typing، دەنگ/هەپتیک و پێشنیاری وشە جێبەجێ نەکراون.

## پشکنینی ژینگەی ئێستا
لە ژینگەی دروستکردنی فایلدا Java 21 هەیە، بەڵام `gradle` و Android SDK دیاری نەکراون. بۆیە لەم ژینگەیەدا ناتوانرێت APK کۆمپایل بکرێت تا Gradle و Android SDK دابین بکرێن.
